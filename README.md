# Cordeiro Group

Site institucional em Next.js 16, React, TypeScript e Tailwind CSS 4.

## Iniciar

```sh
npm install
npm run dev
```

Abra o endereço local exibido no terminal. Para produção: `npm run build` e `npm start`.

Esta primeira entrega implementa o sistema visual, Header, Hero da Home, apresentação inicial das três marcas e rodapé de contato. Consulte `docs/IMPLEMENTACAO.md` para fontes, assets, decisões e próximas etapas. O site permanece local, sem publicação, e com indexação desativada até a finalização.
